The dataset contains hourly records from a bike sharing system in London (2015–2016), including temperature, humidity, wind speed, weather code, and whether the day is a holiday or weekend.

Model: LightGBM (Gradient Boosting)

Target: cnt — number of bikes rented per hour

Evaluation Metric: RMSE (Root Mean Squared Error)
